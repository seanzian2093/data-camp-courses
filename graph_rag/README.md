# Graph RGA with LangChain and Neo4j

A DataCamp online course

## Requirements

* Python 3.12
  * Packages in `requirements.txt`
* Neo4j Community Edition
  * Run local instance
  * Intall APOC plugin

## Create Relationship

Create `Relationship` of `WRITTEN_BY`

## Save Graph Document

Save `GraphDocument` to a `Neo4jGraph` database that runs locally or somewhere else.

## Populate Fake Data

## Run Cypher Statement
